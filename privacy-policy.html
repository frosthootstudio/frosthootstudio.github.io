Kebijakan Privasi

Berlaku sejak: 2026 // Pengembang: FrostHoot Studio

FrostHoot Studio (“kami”) menghormati privasi Anda. Dokumen ini menjelaskan bagaimana data Anda diperlakukan saat menggunakan aplikasi dan layanan digital yang kami kembangkan, termasuk aplikasi konsumen Waktu Shalat maupun sistem utilitas kerja.

1. Prinsip Utama: Privasi dan Offline-First

Sebagian besar aplikasi kami dirancang dengan pendekatan Offline-First. Ini berarti data pengguna diproses secara lokal pada perangkat Anda:

  • Data Lokasi (GPS): Digunakan semata-mata pada perangkat untuk menghitung waktu ibadah atau koordinat lokal dan tidak pernah dikirimkan atau disimpan di server eksternal kami.
  • Data Preferensi & Rekam Jejak: Bookmark, catatan harian, dan checklist ibadah disimpan di memori lokal ponsel Anda (menggunakan SQLite / Hive Box terenkripsi lokal).

2. Pengumpulan Data Anonim & Analitik

Untuk memastikan kestabilan aplikasi, kami dapat mengumpulkan data crash dan telemetri teknis yang sepenuhnya anonim (tanpa identitas pribadi) seperti tipe perangkat, versi sistem operasi, dan log galat (stack trace) guna memperbaiki bug.

3. Iklan & Layanan Pihak Ketiga

Aplikasi unggulan kami (seperti Waktu Shalat) berprinsip 100% Bebas Iklan untuk kenyamanan pengguna. Jika terdapat aplikasi lain yang menggunakan integrasi pihak ketiga (misalnya Google Calendar API untuk sinkronisasi hari libur), data hanya digunakan sesuai izin spesifik yang diberikan oleh pengguna.

4. Hak dan Kontrol Pengguna

Anda memiliki kendali penuh atas data Anda. Pada aplikasi kami yang menyediakan fitur Backup & Restore, Anda dapat mengekspor seluruh data pribadi Anda ke format file mandiri (JSON) atau menghapusnya kapan saja dengan menghapus instalasi aplikasi.

5. Kontak Kami

Jika Anda memiliki pertanyaan seputar kebijakan privasi ini atau ingin mengajukan masukan terkait keamanan data, silakan hubungi kami melalui email:
